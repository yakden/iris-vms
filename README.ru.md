# Iris — видеонаблюдение с ИИ on-premise (VMS)

**Автономная видеоаналитика на одной GPU: детекция в реальном времени, запись событий, аналитика
людей, распознавание речи в текст и встроенный аудит безопасности камер — целиком на вашем железе.
Без облака. Privacy-first.**

[Сайт](https://iris.monmyip.io) · [Документация](https://docs.iris.monmyip.io/ru/) · [Скачать](https://iris.monmyip.io/ru/#trial) · [English](README.md)

Iris превращает ваши RTSP-камеры в ИИ-платформу реального времени, работающую **на одной NVIDIA GPU**
на вашей площадке. Видео, аудио и метаданные не покидают вашу машину. По умолчанию — только детекция;
биометрия включается явно и по согласию.

## Установка

> Установка Iris означает принятие [Лицензионного соглашения](EULA.ru.md) ([EN](EULA.md)).
> Оставьте ключ лицензии пустым, чтобы начать **бесплатный 7-дневный триал** (только онлайн).

**Linux** — одна команда (ставит Docker, сам определяет NVIDIA GPU, загружает образ, запускает стек):

```bash
curl -fsSL https://iris.monmyip.io/downloads/iris-install.sh | sudo bash
# с ключом лицензии:
curl -fsSL https://iris.monmyip.io/downloads/iris-install.sh | sudo IRIS_TOKEN=xxxx bash
```

**macOS 12+** — установите и запустите [Docker Desktop](https://www.docker.com/products/docker-desktop), затем:

```bash
curl -fsSL https://iris.monmyip.io/downloads/iris-install.sh | bash
```

macOS работает только на CPU (для ознакомления). Нативную поддержку GPU (Apple Silicon) добавим при спросе.

**Windows 10/11** — скачайте и запустите установщик (сам настроит WSL2 + Docker + NVIDIA):

➡️ **[iris-setup.exe](https://iris.monmyip.io/downloads/iris-setup-1.60.0.exe)** · проверьте по [SHA256SUMS](SHA256SUMS)

После установки откройте **http://127.0.0.1:8120**.

## Возможности

- 🎯 **Детекция и запись в реальном времени** — люди, транспорт и другое на неблокирующем конвейере; клипы событий из тёплого буфера почти без нагрузки на CPU.
- 📊 **Аналитика людей** — подсчёт, время пребывания, праздношатание, оповещения о скоплении в зонах.
- 🗣️ **Речь-в-текст и перевод** — живые субтитры и транскрипты сохранённых клипов.
- 🔒 **Встроенный аудит безопасности камер** — проверка вашего парка CCTV на уязвимости RTSP/ONVIF/DVRIP/Hikvision/XM.
- 🧠 **Кросс-камерные личности** *(opt-in)* — устойчивые личности с привязкой к лицу между камерами. Требует вашего правового основания на биометрию и коммерческой лицензии на модель лиц; **выключено по умолчанию**.

## Требования и место на диске

| | |
|---|---|
| **ОС** | Windows 10 (2004+)/11, Linux x86-64 или macOS 12+ (64-бит) |
| **GPU** | NVIDIA (напр. T4/L4) — используется автоматически; CPU-фолбэк для ознакомления |
| **Диск** | **~15 ГБ на Windows, ~12 ГБ на Linux/macOS** — образ ~7,5 ГБ + модели ~0,9 ГБ + ~3 ГБ временной загрузки + запас под записи |

Объём фиксирован независимо от включённых функций (отключение подсистемы экономит GPU/CPU в
рантайме, но не место на диске).

## Приватность, лицензирование и модели

- **On-prem / офлайн.** Iris работает на вашем железе; ничего не покидает площадку. Опциональная
  проверка лицензии передаёт только id лицензии + отпечаток железа — никаких персональных данных.
- **По умолчанию только детекция.** Биометрия (лица, голос) — явный opt-in по согласию; с учётом
  152-ФЗ / GDPR / EU AI-Act.
- **Чистые по лицензии модели.** В раздаваемой сборке — модели Apache-2.0 / MIT (детектор RT-DETR),
  без AGPL и research-only весов.
- Условия: **[EULA.ru.md](EULA.ru.md)** · **[EULA.md](EULA.md)**. Install-скрипты этого репозитория —
  под MIT ([LICENSE](LICENSE)); само ПО Iris лицензируется по EULA.

## Управление стеком

После установки из каталога установки (`/opt/iris` на Linux, `~/Iris` на macOS):

```bash
docker compose -f docker-compose.yml [-f docker-compose.gpu.yml] ps      # статус
docker compose -f docker-compose.yml [-f docker-compose.gpu.yml] logs -f # логи
docker compose -f docker-compose.yml [-f docker-compose.gpu.yml] down    # остановить
```
